# Website Desa Wonosari — Portable

Sudah dibersihkan dari Canva bootstrap dan SDK internal. Gambar `canva://...` diganti menjadi path lokal `assets/images/...`.

Tambahkan foto asli sesuai nama file yang dirujuk di `index.html`. Jika belum ada, browser memakai `placeholder.svg`.

Dependensi eksternal non-Canva yang dipakai: Tailwind CDN, Lucide Icons CDN, Google Fonts, dan link video Google Drive.
